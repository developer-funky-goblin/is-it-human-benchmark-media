Add Perl to the list of "Influenced By", links to sources can be found in the talk section. Reasoning: It's not only very obvious that perl influenced methods in the Array, String and RegEx objects by name and semantic. The original source code of JavaScript is explicitly referencing Perl in the comments on numeral occasions. Perl might be an unpopular language in 2025 but was very popular at the time of the creation of JS. The "use strict" feature in newer instances of JS is a straight forward copy from Perl.
